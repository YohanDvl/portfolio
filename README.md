# Portafolio Profesional Freelance — Yohan Maldonado

Sitio web de portafolio profesional de alto impacto diseñado para la captación y cierre de contratos en **Workana** y plataformas de trabajo freelance internacional.

---

## 🚀 Tecnologías & Estándares de Diseño

- **HTML5 Semántico**: Conforme a estándares W3C, accesibilidad WCAG 2.2 y metaetiquetas OpenGraph optimizadas.
- **Vanilla CSS Moderno**: Sistema de variables CSS, CSS Grid, Flexbox, desenfoques de vidrio (*glassmorphism*), paleta cromática Deep Tech y microanimaciones sin dependencias externas pesadas.
- **JavaScript (ES6+) Nativo**: Lógica de calculadora reactiva de presupuesto, filtrado dinámico de proyectos, modales de arquitectura de casos de estudio y acordeón de preguntas frecuentes.
- **Tipografías**: Plus Jakarta Sans & JetBrains Mono vía Google Fonts.

---

## 🎛️ Componentes & Herramientas Incluidas

1. **Hero de Alta Conversión**: Propuesta de valor clara, indicador de disponibilidad en tiempo real y métricas de confianza en ingeniería.
2. **Comparativa de Calidad**: Diferenciador tangible frente al desarrollo improvisado (Clean Code, OWASP, pruebas automáticas, cero deuda técnica).
3. **Catálogo de Proyectos Destacados**:
   - **EventConnect**: Plataforma empresarial de ticketing con arquitectura hexagonal, WebSockets, control de aforo en tiempo real, SQLite WAL, agente de voz Super Admin y portal de arquitectura C4 interactivo.
   - **Cartagena Tours Platform**: Plataforma de reservas turísticas desarrollada con React + Vite y backend ligero en Node.js/SQLite.
   - **PrestamoApp / PrestamoTCP**: Sistema cliente-servidor multihilo en Java 17 sobre Sockets TCP con motor de amortización y generación de reportes PDF.
   - **Laboratorio de Arquitectura Hexagonal**: Catálogo de anti-patrones y refactorización a DDD con puertos y adaptadores.
   - **Suite de Calidad de Software PHP**: Framework de aseguramiento de calidad con ISO 29119 y auditoría OWASP Top 10.
   - **Generador & Validador QR**: Solución móvil y web con Ionic, Angular y Capacitor para validación de accesos offline.
4. **Calculadora Interactiva de Alcance & Presupuesto**: Herramienta orientativa que permite al cliente calcular tiempos e inversión en tiempo real, generando un mensaje formateado listo para enviar por chat de Workana.
5. **Estudios de Caso Interactivos**: Modales técnicos con el problema de negocio, solución arquitectónica y stack.
6. **FAQ para Clientes**: Respuestas directas sobre contratos por hitos, pagos en depósito en garantía, propiedad del código y soporte post-entrega.

---

## 💻 Ejecución Local

No requiere instalación de dependencias ni procesos de compilación complejos:

```bash
# Abrir directamente en el navegador:
open index.html # En macOS
# O en Windows:
start index.html
```

O servirlo con cualquier servidor estático local:
```bash
npx serve .
# o
python -m http.server 8000
```
